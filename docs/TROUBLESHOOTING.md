# 문제 해결

## 앱이 종료되지 않아 Finish 또는 Restore가 중단됨

도구는 정상 종료만 요청하고 강제 종료하지 않습니다. 저장 확인 창이나 응답 없는 창을 처리하고 앱을
직접 종료한 뒤 같은 명령을 다시 실행하세요. 종료 확인 실패 시 Vault는 변경하지 않습니다.

## Push가 거부됨

자동 merge나 `-X ours` 재시도는 하지 않습니다. 로컬과 원격이 모두 진행된 경우 세션 삭제가 다시
살아날 수 있으므로 중단하는 것이 정상입니다.

로컬 commit만 앞서 있고 원격이 그대로라면 같은 명령을 다시 실행해 미전송 commit을 먼저
Push합니다. 원격도 변경됐다면 `git status`, `git log --left-right HEAD...origin/main`을 확인하고
사용자가 어느 상태를 유지할지 결정합니다.

## Codex 파일은 복원됐지만 사이드바에 안 보임

Codex 사이드바 즉시 반영은 best-effort입니다.

1. Codex를 완전히 종료하고 다시 실행합니다.
2. 여전히 안 보이면 앱을 업데이트합니다.
3. Start를 다시 실행합니다.

`state_5.sqlite`를 직접 수정하지 마세요. 파일과 앱 버전이 맞지 않으면 더 큰 손상이 생길 수 있습니다.

진단 로그는 다음 위치에 있습니다.

```powershell
Get-Content "$env:LOCALAPPDATA\AgentSessionSync\Logs\latest.json" -Raw
```

## 복원한 대화가 다음 Finish에서 다시 Archived로 내려감

복원 자체는 활동 시각을 바꾸지 않습니다. 원문 마지막 timestamp가 30일 기준을 넘었고 새 활동을
남기지 않았다면 다시 Archived로 내려가는 것이 정상입니다. 원문은 Vault에 남으므로 다시 복원할 수
있습니다.

## 삭제한 Codex 대화가 다시 나타남

Codex 삭제는 `보관 → 보관함에서 삭제` 두 단계입니다. 보관만 한 상태에서는 원문이
`archived_sessions`에 있으므로 아직 삭제로 판정하지 않습니다. 최종 삭제 후 Finish가 성공해야
Vault 최신 트리에서도 제거되고, 다른 PC의 다음 Start에서 로컬 사본이 제거됩니다.

## 30일 지난 대화가 계속 보임

Finish가 성공하여 Vault Archived 이동과 로컬 정리를 완료했는지 확인합니다. Push 실패 시에는
데이터 손실을 막기 위해 로컬 정리와 체크포인트 갱신을 하지 않습니다.

## 지원하지 않는 세션 형식으로 중단됨

앱을 업데이트했거나 설치 방식이 달라져 `session_meta` 구조가 알려진 형식과 다를 수 있습니다.
이때는 원문이나 Vault를 수정하지 않는 것이 정상입니다. 문제 파일과 앱 버전을 확인하고 adapter를
추가한 뒤 다시 실행합니다.
