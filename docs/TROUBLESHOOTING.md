# 문제 해결

## 앱이 종료되지 않아 Finish 또는 Restore가 중단됨

Finish는 먼저 Vault·checkpoint·gzip 호환성을 검사한 뒤 정상 종료를 요청합니다. 트레이 상주
프로세스가 남으면 등록된 앱의 검증된 루트 트리만 강제 종료합니다. Restore는 강제 종료하지 않으므로
저장 확인 창이나 응답 없는 창을 처리하고 직접 종료한 뒤 다시 실행하세요.

## Push가 거부됨

도구는 원격을 다시 fetch하고 최대 3회 merge·push로 합류합니다. 겹친 경로는 경고에 표시되며
현재 호스트 사본이 우선됩니다. 3회 모두 거부되거나 자동 merge 자체가 실패한 경우에만 중단합니다.

checkpoint가 없거나 Vault HEAD와 달라도 Finish는 경고 후 계속합니다. 이때 Codex 로컬 부재는
삭제로 추론하지 않습니다. checkpoint는 잠금이나 실행 허가가 아니라 삭제 판정의 보조 증거입니다.

## Codex 파일은 복원됐지만 사이드바에 안 보임

Codex 사이드바 즉시 반영은 best-effort입니다.

1. Codex를 완전히 종료하고 다시 실행합니다.
2. 여전히 안 보이면 앱을 업데이트합니다.
3. Start를 다시 실행합니다.

`state_5.sqlite`를 직접 수정하지 마세요. 파일과 앱 버전이 맞지 않으면 더 큰 손상이 생길 수 있습니다.

진단 로그는 다음 위치에 있습니다.

```powershell
Get-Content "$env:LOCALAPPDATA\AgentSessionSync\Logs\latest.json" -Raw
```

## 복원한 대화가 다음 Finish에서 다시 Archived로 내려감

복원 자체는 활동 시각을 바꾸지 않습니다. 원문 마지막 timestamp가 30일 기준을 넘었고 새 활동을
남기지 않았다면 다시 Archived로 내려가는 것이 정상입니다. 원문은 Vault에 남으므로 다시 복원할 수
있습니다.

## 삭제한 Codex 대화가 다시 나타남

Codex 삭제는 `보관 → 보관함에서 삭제` 두 단계입니다. 보관만 한 상태에서는 원문이
`archived_sessions`에 있으므로 아직 삭제로 판정하지 않습니다. 최종 삭제 후 Finish가 성공해야
Vault 최신 트리에서도 제거되고, 다른 PC의 다음 Start에서 로컬 사본이 제거됩니다.

## Claude 삭제 마커를 해석할 수 없어 Finish가 중단됨

Claude의 삭제 마커에는 앱 세션 ID만 있고 원문 canonical ID는 없습니다. 도구는 마지막 checkpoint에
저장된 매핑으로 둘을 연결합니다. 매핑이 없는 마커를 추측해서 처리하면 삭제한 대화를 다시 올리거나
살아 있는 대화를 지울 수 있으므로 전체 Finish를 중단합니다. 초기화 전 잔재라면 세팅 절차로 돌아가
앱 저장소를 정리하고, 정상 운용 중 생겼다면 마커와 checkpoint를 보존한 채 원인을 확인하세요.

## 30일 지난 대화가 계속 보임

Finish가 성공하여 Vault Archived 이동과 로컬 정리를 완료했는지 확인합니다. Push 실패 시에는
데이터 손실을 막기 위해 로컬 정리와 체크포인트 갱신을 하지 않습니다.

## 지원하지 않는 세션 형식으로 중단됨

앱을 업데이트했거나 설치 방식이 달라져 지원하는 원문 구조와 다를 수 있습니다. 이때는 원문이나
Vault를 수정하지 않는 것이 정상입니다. 문제 파일과 앱 버전을 확인하고 도구가 해당 형식을 지원하는지
확인한 뒤 다시 실행합니다. 이 공개 도구의 지원 앱은 Claude와 Codex입니다.
